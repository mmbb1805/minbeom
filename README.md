# Minbeom Kim

Academic curriculum vitae and profile for Minbeom Kim, Ph.D. The page is static HTML and CSS, with a small script for the section menu, color theme, and publication filter. It is meant to be published with GitHub Pages from the repository root.

## Publish on GitHub Pages

After these files are on `main`:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then save.

The site address is [https://mmbb1805.github.io/minbeom/](https://mmbb1805.github.io/minbeom/).

## Files

- `index.html` — profile page
- `style.css` — layout, theme, and print styles
- `assets/favicon.svg` — icon
- `assets/minbeom-kim.jpg` — profile portrait
- `assets/Minbeom_Kim_CV.docx` — curriculum vitae download

Education, research, publications, experience, the patent and technology transfer, awards, skills, and contact details are taken from that curriculum vitae.
